# Сервис опросов
 
Веб-сервис для создания анкет, прохождения опросов, агрегирования результатов и экспорта данных.
 
> Статус: этап 1 (планирование). Код сервиса появится на следующих этапах.
 
## Что умеет сервис (план MVP)
 
- создание опроса с вопросами разных типов;
- публикация опроса и получение ссылки для респондентов;
- прохождение опроса;
- агрегирование результатов;
- экспорт ответов в CSV.
Точный состав MVP будет определён в `docs/01-planning/prioritization.md`.
